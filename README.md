# Telegram-бот с контекстом LLM (ProxyAPI + aiogram)

## Описание

Telegram-бот на **aiogram** с контекстным диалогом через нейросеть **ProxyAPI**.
История диалога хранится в памяти процесса (`MemoryStorage`).

### Стек

- `aiogram` — асинхронная инфраструктура Telegram-бота;
- `llm` — клиент ProxyAPI (OpenAI-совместимый API);
- `common.fsm` + `common.storage` — машина состояний (FSM) и хранение в памяти;
- `common.context` — история реплик с обрезкой по числу и символам.

### Возможности

- Пошаговый ввод параметров `/start`:
  запрос → температура → max_tokens → системное сообщение (опционально);
- Обычный диалог — бот помнит историю и отвечает с учётом контекста;
- Inline-кнопка «Очистить контекст» или команда `/reset`;
- Логирование отправляемых параметров, токенов и ошибок.

## Быстрый старт

```bash
# 1. Активация виртуального окружения
.venv\Scripts\Activate.ps1

# 2. Установка зависимостей
python -m pip install -r requirements.txt

# 3. Запуск бота
python bot.py
```

В `.env` должны быть заданы:

| Переменная | Назначение |
|---|---|
| `PROXYAPI_API_KEY` | Ключ ProxyAPI |
| `TG_BOT_API_KEY` | Токен бота от @BotFather |

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PROXYAPI_API_KEY` | *(обязательно)* | Ключ ProxyAPI |
| `TG_BOT_API_KEY` | *(обязательно)* | Токен Telegram-бота |

## Схема FSM

```
/start
  │
  ▼
[Setup:query] ── текст запроса ──► [Setup:temperature]
                                       │
                                 float 0.0–2.0
                                       │
                                       ▼
                                 [Setup:max_tokens] ── int 1–4000 ──► [Setup:system]
                                                                          │
                                                                   системный промпт (опц.)
                                                                          │
                                                                          ▼
                                                                   [Chat] ←── первый ответ модели
                                                                          │
                                                                   любой текст → ответ модели
```

## Тестовые прогоны

5 реальных вызовов модели **openai/gpt-4.1-mini** (ProxyAPI) с разными параметрами.
Тарифы: ввод 104 ₽/1М токенов, вывод 413 ₽/1М токенов.

| № | Модель | Temperature | Max tokens | Prompt токены | Completion токены | Всего токенов | Стоимость | Эффект |
|---|---|---|---|---|---|---|---|---|
| 1 | gpt-4.1-mini | 0.2 | 64 | 45 | 64 | 109 | ~0.03 ₽ | Сжатость (краткий ответ) |
| 2 | gpt-4.1-mini | 0.7 | 256 | 45 | 147 | 192 | ~0.07 ₽ | Сбалансированность |
| 3 | gpt-4.1-mini | 1.2 | 512 | 45 | 164 | 209 | ~0.07 ₽ | Креативность / развёрнутость |
| 4 | gpt-4.1-mini | 0.2 | 1024 | 45 | 146 | 191 | ~0.07 ₽ | Сжатость (длинный лимит) |
| 5 | gpt-4.1-mini | 1.5 | 1024 | 45 | 170 | 215 | ~0.07 ₽ | Креативность / развёрнутость |

**Промпт:** «Напиши короткий рассказ про кота, который научился программировать.»
**Системное сообщение:** «Ты — полезный ассистент, пишущий краткие и информативные тексты.»

**Наблюдения:**
- `temperature=0.2` — ответы более детерминированные, структурированные, сжатые.
- `temperature=1.2–1.5` — ответы более креативные, с вариациями в сюжете и именах.
- `max_tokens` ограничивает верхнюю границу, но при low temperature фактический объём ответа почти не растёт (модель сама решает, когда закончить).
- Стоимость одного запроса в среднем **~0.07 ₽** (192 токена), что делает бота экономичным при частом использовании.
